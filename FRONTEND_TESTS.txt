FRONTEND TEST INVENTORY
Reviewed: 2026-10-07
Total: 90 helper tests in 16 files, plus 1 browser test in 1 file

Run from frontend/:
  npm test
Single file example (from frontend/):
  node --test src/data/routes.test.js

Scope: Node built-in test runner with strict assertions against frontend data
helpers, bundled catalog rules, request construction, and navigation actions.
Helper tests use browser stubs where needed. The separately run Firefox test
listed below covers rendered interactions and state retention with mocked APIs.
Actual Back/Forward events and visual/CSS correctness are not covered.
Lint and production build are separate checks, not entries in this inventory.
Counts refer to named tests; loops exercise additional cases within each test.
Descriptions summarize actual assertions, not a guarantee of all possible cases.
Update this inventory when tests are added, removed, renamed, or changed.

   Behavior and purpose: Reorders shuffled Astra steps so 10-to-15 prerequisites precede later stars, then groups the continuous 10-to-17 range without changing the input.

   Behavior and purpose: Breaks efficiency ties using original ranking priority while treating ring-1 and ring-2 independently; accepts an empty queue.

   Behavior and purpose: Does not choose a low-star range solely for a payoff seven steps away. The better immediate competitor stays first.

   Behavior and purpose: Keeps another item first when reaching the post-15 payoff is too expensive after counting prerequisites.

   Behavior and purpose: Can commit a two-star range, then reconsider other items instead of forcing a six-star block.

   Behavior and purpose: Requests carry Astra defaults and zero overrides. Grouped ranges sum fractional booms and replacement spending; efficiency and ordering use total cost.

   Behavior and purpose: Builds separate ring entries with their stars and limits, preserves modes/safeguards and explicit false boss status, converts numeric strings, and omits empty potential rows.

   Behavior and purpose: Maps overall potential to outfit and weapon potential to weapon, preserves base weapon offense, and defaults missing stars/rolls to zero/empty arrays.
