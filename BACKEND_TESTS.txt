BACKEND TEST INVENTORY
Reviewed: 2026-10-06
Total: 125 tests in 10 files

Run from the repository root (Windows PowerShell):
  .\.venv\Scripts\python.exe -m unittest discover -s backend/tests -t . -v
Single suite example:
  .\.venv\Scripts\python.exe -m unittest backend.tests.test_api -v
Single test example:
  .\.venv\Scripts\python.exe -m unittest backend.tests.test_potential.PotentialTests.test_ied_stacking -v

Scope: Python unittest suites covering calculator mathematics, bundled data,
request validation, upgrade planning, and equipment-import rules. HTTP tests
use FastAPI TestClient in process; no running API server is needed. Importer
network calls are mocked. Stored reference values are not live verification
of current game rules or third-party services. Controlled distributions and
reduced option pools isolate specific mathematical behaviors where described.
The equipment sample integration test requires Node on PATH; it is skipped
when Node is unavailable. Samples are in examples/equipment/ and requests are
built by frontend/scripts/equipment-samples.mjs.
Counts refer to test methods; loops/subtests exercise additional scenarios.
Descriptions summarize actual assertions, not exhaustive input coverage.
This inventory does not cover production deployment, browser behavior, or
load testing. Update it whenever test names or assertions change.
