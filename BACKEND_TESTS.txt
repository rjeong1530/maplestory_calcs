Run from the repository root:
  .\.venv\Scripts\python.exe -m unittest discover -s backend/tests -t . -v
Single suite:
  .\.venv\Scripts\python.exe -m unittest backend.tests.test_api -v

Scope: calculator mathematics, HTTP contracts, input/admission limits, bundled
probability data, catalog import, and upgrade planning. HTTP tests use in-process
FastAPI TestClient; importer network calls are mocked. Equipment sample integration
requires Node and skips if unavailable. Reference values are stored fixtures, not
live verification of game rules. Loops/subtests contain additional scenarios.

Audit: retained all test methods. Engine and HTTP tests guard different layers;
importer and bundled-catalog tests validate different artifacts. Specific weapon
boss-weight validation overlaps general armor-weight validation but uses a distinct
weapon configuration. Queue cases cover separate admission and cleanup failures.
Latest local run: all 144 tests passed. Existing httpx deprecation warning remains.

Inventory policy: one entry per current named test, grouped by source file.
Historical counts/change logs removed. Descriptions summarize assertions and do
not claim exhaustive input coverage. Update the relevant entry after test changes.
